# MetaMuseum 🎨

**MetaMuseum** is a virtual museum platform that blends interactive 3D art exploration with AI-driven emotion detection and personalized art recommendations. Users can navigate a digital gallery, submit mood-based input (text, image, or audio), and receive artwork suggestions from global collections.

---

## 🔑 Features

### 1. User Authentication & Admin Dashboard
- Secure login and registration system
- Admin panel for user management and system monitoring

### 2. 3D Virtual Gallery
- Built using **Three.js**
- Interactive navigation: walkthrough, zoom, and rotation
- Theme customization based on user preferences

### 3. Emotion Detection Module
- Accepts text, image, or audio as input
- Applies sentiment/emotion analysis models
- Feeds detected emotion into the recommendation engine

### 4. Art Recommendation System
- Integrates with the **Harvard Art Museums API**
- Suggests artwork based on emotion analysis
- Supports artwork categorization (e.g., paintings, sculptures)
- Displays metadata: title, artist, year, description

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Three.js
- **Backend**: Python (Flask/FastAPI)
- **Machine Learning**: TensorFlow, Scikit-learn
- **APIs**: Harvard Art Museums API
- **Database**: PostgreSQL / MongoDB
